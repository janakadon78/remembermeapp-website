# Remember Me — Website

Marketing and support website for the **Remember Me** iOS app, served at
[remembermeapp.online](https://remembermeapp.online).

## Pages

| File | Purpose |
|------|---------|
| `index.html` | Landing page: features, getting started, privacy highlights, FAQ, contact |
| `guide.html` | Full step-by-step user guide |
| `privacy.html` | Privacy Policy |
| `terms.html` | Terms & Conditions |
| `assets/brain-green.svg` | Brand logo |

## Hosting

Static site — no build step. Any static host works (GitHub Pages, Netlify,
Cloudflare Pages). For GitHub Pages: Settings → Pages → deploy from the `main`
branch, then add the custom domain `remembermeapp.online`.
